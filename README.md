## Objetivo do projeto

Este projeto tem como objetivo desenvolver um sistema de recomendação de mangás utilizando a técnica de Similaridade de Cosseno.

A aplicação utiliza informações de uma base de dados de animes e mangás para identificar conteúdos semelhantes e auxiliar os usuários na descoberta de novas obras.

## Tecnologias e recursos utilizados

- Python para processamento dos dados.
- Pandas para manipulação da base de dados.
- Similaridade de Cosseno para comparação dos conteúdos.
- Streamlit para disponibilização da aplicação web.
- MyAnimeList como fonte de informações.
